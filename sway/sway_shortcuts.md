# Sway Keyboard Shortcuts Reference

> **Modifier Key (`$mod`):** `Super` / `Windows Key` (`Mod4`)

---

## 🚀 Basics & System Controls

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Mod4 + Return` | **Open Terminal** | Spawns `foot` terminal emulator |
| `Mod4 + d` | **Application Launcher** | Opens `rofi` launcher menu |
| `Mod4 + Shift + q` | **Kill Window** | Closes the focused window |
| `Mod4 + Shift + c` | **Reload Config** | Reloads Sway configuration files live |
| `Mod4 + Shift + e` | **Exit Sway** | Prompts to exit the Sway Wayland session |
| `Mod4 + Mouse Left` | **Drag Window** | Drag/move floating container |
| `Mod4 + Mouse Right` | **Resize Window** | Resize container dynamically |

---

## 🎯 Navigation & Window Focus

| Shortcut | Action |
| :--- | :--- |
| `Mod4 + h` / `Mod4 + Left` | Focus Left |
| `Mod4 + j` / `Mod4 + Down` | Focus Down |
| `Mod4 + k` / `Mod4 + Up` | Focus Up |
| `Mod4 + l` / `Mod4 + Right` | Focus Right |
| `Mod4 + a` | Focus Parent Container |
| `Mod4 + space` | Toggle Focus between Tiling & Floating layers |

---

## 🚚 Window Movement

| Shortcut | Action |
| :--- | :--- |
| `Mod4 + Shift + h` / `Mod4 + Shift + Left` | Move window Left |
| `Mod4 + Shift + j` / `Mod4 + Shift + Down` | Move window Down |
| `Mod4 + Shift + k` / `Mod4 + Shift + Up` | Move window Up |
| `Mod4 + Shift + l` / `Mod4 + Shift + Right` | Move window Right |

## 🖥️ Workspaces

| Shortcut | Action |
| :--- | :--- |
| `Mod4 + 1` ... `Mod4 + 0` | Switch to Workspace `1` through `10` |
| `Mod4 + Shift + 1` ... `Mod4 + Shift + 0` | Move focused window to Workspace `1` through `10` |

## 📐 Layout Controls

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Mod4 + b` | **Split Horizontal** | Split container horizontally |
| `Mod4 + v` | **Split Vertical** | Split container vertically |
| `Mod4 + s` | **Stacking Layout** | Set workspace layout to stacked |
| `Mod4 + w` | **Tabbed Layout** | Set workspace layout to tabbed |
| `Mod4 + e` | **Toggle Split** | Toggle split mode |
| `Mod4 + f` | **Fullscreen** | Toggle fullscreen mode for active window |
| `Mod4 + Shift + space` | **Toggle Floating** | Toggle focused window between tiling & floating |

## 📥 Scratchpad

| Shortcut | Action |
| :--- | :--- |
| `Mod4 + Shift + -` | Send focused window to scratchpad |
| `Mod4 + -` | Show / cycle through scratchpad windows |

---

## ↔️ Resize Mode (`Mod4 + r`)

Press `Mod4 + r` to enter Resize Mode, then use the following keys:

| Key | Action |
| :--- | :--- |
| `h` / `Left` | Shrink width by 10px |
| `j` / `Down` | Grow height by 10px |
| `k` / `Up` | Shrink height by 10px |
| `l` / `Right` | Grow width by 10px |
| `Return` / `Escape` | **Exit Resize Mode** |

## 🔊 Audio & Media Controls

| Shortcut | Action |
| :--- | :--- |
| `XF86AudioRaiseVolume` | Increase volume |
| `XF86AudioLowerVolume` | Decrease volume |
| `XF86AudioMute` | Toggle output audio mute |
| `XF86AudioMicMute` | Toggle microphone mute |
| `XF86AudioPlay` | Play / Pause media player |
| `XF86AudioStop` | Stop media playback |
| `XF86AudioNext` | Skip to next track |
| `XF86AudioPrev` | Skip to previous track |
| `XF86AudioForward` | Seek forward 10 seconds |
| `XF86AudioRewind` | Seek backward 10 seconds |
